# 车型：昆仑

昆仑是车型名称，也是内部代号。据 Jeff 答 2026-10-31 #1 与 #5。#5 原话：「昆仑有不同的车型 n1 n2n3，这里需要有车型表 实际你可以查小米澎程就是昆仑 昆仑是内部代号。」

小米澎程就是昆仑。对外对应这张表时，写法用原话「澎程」，不改成别的字。这张表只有回答和会议里已经写下的称呼，没有补车型参数。

kunlun 是空间平台。据 Jeff 答 2026-11-10 #2。原话：「kunlun是空间平台」。modena 与 Lemans 是运动平台，不是这张表上的子车型。市场销售名分开记：[SU7](车型-SU7.md) 是 modena，[YU7](车型-YU7.md) 是 Lemans。未来 LUX 与 Mann 组成豪华平台，见 [LUX](车型-LUX.md)、[Mann](车型-Mann.md)。不把昆仑收成这三张平台里的另外两张。

同一条 #1 还写：测试发现和拦截问题的过程贯穿整个研发阶段，所以一个月应该还在这个车型的研发周期内。M17 摘要写 27 例在研发端拦截，评审章节写昆仑试点 1 个月拦截 27 例。两种说法不冲突，两句都保留。见 [M17](../meetings/2026-10-30-汽车部项目评优答辩讨论.md#alert-智能预警)。

昆仑、小米澎程是名字。下面分成两张表：子车型是 N1、N2、N3；电子电气架构是 EEA 2.0、EEA 3.0、EEA 4.0。两套编号不混在一张表里。

| 称呼 | 位置 | 依据 |
|---|---|---|
| 昆仑 | 内部代号，也是车型名称 | Jeff 答 2026-10-31 #5、#1 |
| 小米澎程 | 就是昆仑。原话写作「澎程」 | Jeff 答 2026-10-31 #5 |

## 电子电气架构（EEA）

正名写作 EEA 2.0、EEA 3.0、EEA 4.0。EEA 2.0 也就是电子电气架构 2.0。

据 Jeff 答 2026-11-01 #1 追问。原话：「安露特，是alert；同时这个上下文中，你要加入电子架构的概念，目前的昆仑车型搭载的是2.0架构。电子架构当前发展到了2.0，3.0，4.0，越往后对埋点的支持力度越大。」追问里的「电子架构」就是这套。

据 Jeff 答 2026-11-01 追加（同日稍后）。原话：「对EA2.0，准确的说就是EEA2.0」。原话没有空格，也没有写出「电子电气」四个字。M15 纪要原文写作「EA 2.0」，EA 是原文写法，准确写法是 EEA 2.0。追加原话只点了 EEA2.0。EEA 3.0、EEA 4.0 用同一套正名，原话没有单独写出这两个写法。

#1 那句原话仍是他在要上下文，没有在下一代和当代之间选。追问给的是架构，不把昆仑 2.0 收成下一代昆仑车型。

| 架构 | 这页怎么用 | 依据 |
|---|---|---|
| EEA 2.0 | 目前的昆仑车型搭载的是这套 2.0。M6 摘要埋点那句的「昆仑2.0版本车型」指搭载 EEA 2.0 的昆仑。不是子车型 N2 的别名。M15 原文写作 EA 2.0。 | Jeff 答 2026-11-01 #1 追问与追加（同日稍后）；[M6](../meetings/2026-10-23-汽车相关业务推进事宜讨论.md) 摘要；[M15](../meetings/2026-10-28-汽车远程诊断Alert落地规划讨论.md) |
| EEA 3.0 | M6 同段写「仅后续3.0版本车型可支持」。这是 EEA 3.0，比 2.0 更能支持埋点。不收成子车型 N3。 | M6 摘要，加上 Jeff 答 2026-11-01 #1 追问 |
| EEA 4.0 | 架构当前发展到 4.0。越往后，对埋点的支持力度越大。M6 没有单独写 4.0。 | Jeff 答 2026-11-01 #1 追问 |

M6 摘要和逐字稿里的「安露特」是 alert，按 Alert 埋点理解。原话写作「是alert」。纪要原文不改。

## N70

昆仑 N70 出现在 M17 成效章节，写法是「昆仑 N70」。见 [M17](../meetings/2026-10-30-汽车部项目评优答辩讨论.md#alert-智能预警)。M18 逐字稿另有「鹏程 N90 和 N70」。

据 Jeff 答 2026-11-01 追加（同日稍后），N70 对应哪款他暂不知，可以忽略，将来他主动问清楚再告知。原话：「N70对应哪款我确实不知道，可以忽略，将来遇到我问清楚告诉你」。不再列为待问。仍不归入 N1、N2 或 N3，也不放进 EEA 表。N90 仍不收成子车型。

#2 原话仍在：「N70应该对应的是N1-N3中的某款，目前我也不清楚」。追加把它从待问里拿掉，没有改成已经归入某一款。

## 澎程的写法

据 Jeff 答 2026-11-01 #3，M18 的「鹏程」「鹏城」是「澎程」的听写错，都指昆仑对外名（小米澎程）。原话：「是，听写错」。此前只因听写留下的「待核对」去掉。纪要里的两个写法仍留在会议页，不改 raw。见 [M18](../meetings/2026-10-30-项目答辩与相关问题讨论.md)。

M15 章节点到的鹏程是到场的人，会议页不建人物页。#3 没有把这个人收成车型。这条仍不并进车型表。

## M21 的「征程」

开会日是 2026-10-30，妙记录入是 2026-11-05。据 Jeff 答 2026-11-13 #3。原话：「开会日是对的，妙记可能是后来记的。」

逐字稿写「全新的增程车型征程」，并写「合格的征程」。摘要写「全新增程车型」。据 Jeff 答 2026-11-11 #2，征程应该是澎程。原话：「应该是澎程。」「应该是」留着，不改 raw。增程仍是摘要里的字，这句没有把增程改成澎程。澎程就是本页的对外名。见 [M21](../meetings/2026-11-05-整车质控平台项目汇报与讨论.md)。

## M22、M23 里另有的写法

M22、M23 的开会日同样是 2026-10-30，妙记录入是 2026-11-05。据 Jeff 答 2026-11-13 #3。日期上的待核对解除。

M22 爆胎首发：正确名字是澎程。据 Jeff 答 2026-11-07 #3。原话：「澎程是正确的名字」。鹏程、鹏城是纪要变体，指回澎程。摘要的「小米苏7」保留原文，不作为这句首发的正确名字。已有事实仍是小米澎程就是昆仑，本条没有另写一个不同的澎程。成果章的「小米苏七」这几条回答没有点名，不自行收成 SU7，也不收成这句首发。见 [M22](../meetings/2026-11-05-主动安全与爆胎防护项目汇报讨论.md)、[车型：SU7](车型-SU7.md)。

横展对象：乐芒和 M20 的勒芒是同一款，两场 LUX 是同一个。据 Jeff 答 2026-11-10 #3。曼岛是 Mann 的中文名。见 [车型：YU7](车型-YU7.md)、[车型：LUX](车型-LUX.md)、[车型：Mann](车型-Mann.md)。

M23：摘要写后续跟进昆仑，章节写预期昆仑，逐字稿是「苏西预期昆仑」。据 Jeff 答 2026-11-13 #1，讲的是 YU7 和昆仑。原话：「讲的是YU7，昆仑。」「预期昆仑」不是另一款车。苏西是 SU7，据 Jeff 答 2026-11-11 #3，不把苏西收成 YU7。慢保是曼岛。Z09 是听错了，正确是 RC09，不是车型或项目代号。据 Jeff 答 2026-11-12 #3。见 [M23](../meetings/2026-11-05-整车软件体验量化准出体系分享.md)。
