# 车型：YU7

市场销售名。研发内部代号是 Lemans。据 Jeff 答 2026-11-10 #2。原话：「Lemans就是YU7」。原话这一处写作「Lemans」，前面「分别是」里写作「lemans 27B」。两个写法都留着。

modena 与 Lemans 是运动平台。见 [车型：SU7](车型-SU7.md)。

| 称呼 | 位置 | 依据 |
|---|---|---|
| YU7 | 市场销售名 | Jeff 答 2026-11-10 #2 |
| Lemans / lemans | 研发内部代号。原话两处写法都留着 | Jeff 答 2026-11-10 #2 |
| lemans 27B | 车型代号。题目里的勒芒 R7B 按「分别是」的第二项对到这一款。原话没有再写勒芒、R7B | Jeff 答 2026-11-10 #2 |
| 勒芒 | M20 章节的项目名，写作「勒芒 R7B」 | M20。与 lemans 27B 的对应见上一行 |
| 乐芒 | M22 摘要的横展对象。和 M20 的勒芒是同一款 | Jeff 答 2026-11-10 #3。原话：「都是同一个」 |

M23「苏西预期昆仑」讲的是 YU7 和昆仑。据 Jeff 答 2026-11-13 #1。原话：「讲的是YU7，昆仑。」苏西本身是 SU7，据 Jeff 答 2026-11-11 #3，不把苏西收成 YU7。「预期昆仑」不是另一款车。

纪要里另有「玉七」「玉7」。这几条回答没有点这些字，不自行归进本页。
