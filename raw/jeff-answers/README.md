# Jeff 回答层

本目录存放 Jeff（刘君峰）对每日十问的书面回答，与 [`raw/meetings/`](../meetings/) 同为事实来源。规范见 [AGENTS.md 第 7 节](../../AGENTS.md)。目录入口在 [wiki/index.md](../../wiki/index.md)。

Jeff 于 2026-10-31 书面同意新增本层，原话：「同意新增回答层 先不用私有库」。回答放在本公开库，不另建私有库。

## 用途

回答层用于沉淀已经写下的三类内容：

- 业务规则
- 因果关系
- 待办的真实状态

wiki 引用写法：「据 Jeff 答 2026-11-01 #3」。这是格式示例，不是已有回答。日期和题号必须对得上 `YYYY-MM-DD.md` 里的那一条。

会议纪要里未勾选的待办保持未勾选。只有 Jeff 的回答写明某待办已完成时，编译层才可勾选，并注明出处。

## 格式

- 一天一个文件：`YYYY-MM-DD.md`。日期是 Jeff 写下回答的日期。
- 每条四项：题号、原问题、问题出处（如 M15）、Jeff 原话回答。缺一项不入库。
- 原问题和原话逐字保留，不摘要、不润色。出处照 Jeff 所写；不要编会议编号。
- 入库提交之后不改字、不改文件名。纠错另写更正条目，指向被更正的日期和题号，不覆盖原条目。
- 本 README 只说明用途和格式。不要把问题或回答写进来。没有原话就不要建当天的文件。

目前没有回答文件。

```markdown
- 更正对象：YYYY-MM-DD #题号
- Jeff 原话：
```
